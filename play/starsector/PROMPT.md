# Initial Codex play prompt

Use this as the first campaign task.

> Play Starsector.
>
> Start a fresh campaign yourself and make it your continuing save. Choose the new-game setup, fleet direction, objectives, contracts, travel, purchases, fights, retreats, refits, and longer-term priorities yourself. The goal is to learn the installed game, survive, and improve your position through ordinary play.
>
> Read `STARSSECTOR_PLAY.md`, then follow Preflight's current repository instructions and automation route selector before launching or attaching. Use the real UI where appropriate and Preflight's reviewed semantic controls where they already exist. Pause freely. Observe the result of each action before making the next decision.
>
> You may use tooltips and look up guides/mechanics when useful. Build a compact guide for yourself under `play/starsector/`; distinguish observed facts, external guide advice, hypotheses, and repeatedly verified rules. Do not write a click-by-click transcript.
>
> While playing, make recurring work easier when it is clearly worthwhile: a helper, deterministic calculation, read-only observation, recovery rule, reviewed semantic action, Byheart capability, or concise instruction. Keep contextual game decisions contextual.
>
> Normal play should continue on the same save. Use checkpoint copies only for deliberate experiments, controller recovery, or comparing genuinely uncertain alternatives. Do not quietly roll back campaign consequences.
>
> Play for roughly 30 in-game days for the first session, or until genuinely blocked. Before stopping, update `play/starsector/CAMPAIGN.md` so another Codex session can continue the exact same campaign.

The next session should normally be simpler:

> Continue the existing Starsector campaign from `play/starsector/CAMPAIGN.md`. Read the current playbook and learning ledger, inspect the live save, and keep playing.
