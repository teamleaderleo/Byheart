# Starsector agent campaign workspace

This directory is working memory for a continuing Codex-played Starsector campaign.

Start with [`../../STARSSECTOR_PLAY.md`](../../STARSSECTOR_PLAY.md).

Keep these files concise and current:

- `CAMPAIGN.md` — exact active save/campaign identity, current position, resources, current objective, next action, and important recent decisions.
- `PLAYBOOK.md` — durable mechanics, heuristics, UI procedures, economic/combat/fleet lessons worth reusing.
- `LEARNING.md` — open hypotheses, experiments, mistakes, conflicting advice, and candidates for helpers/capabilities.

Do not log every click or every model thought. Byheart/Preflight evidence owns execution detail. These notes exist so the next agent session can continue playing competently without rereading a full history.

Useful evidence tags: `[observed]`, `[guide]`, `[hypothesis]`, `[verified]`.
